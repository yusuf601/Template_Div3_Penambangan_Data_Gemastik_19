# Core-lite Foundation (`utils/core`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `utils/core` package (Core-lite) for the 5-hour offline Gemastik final (1 GPU PC + CPU support laptops), providing actionable `[Masalah]`/`[Perbaikan]` errors, vectorized canonical IDs and fast hashing, `BaseConfig` auto-resolution, standalone/reusable leak-free CV folds, portable `RunManager` with `sync_leaderboard` and per-fold resume, `BasePipeline` with 3 primary hooks + `max_minutes` budget, presentation-ready `summary.md`/plots, and OOF blending (`mean` + `weights`).

**Architecture:** Single-responsibility modules under `utils/core/` (`errors`, `io`, `seed`, `metrics`, `config`, `cv`, `run`, `report`, `pipeline`, `ensemble`) with zero circular imports and zero network access. `BasePipeline.run()` orchestrates config resolution, CV-aware debug subsampling, pre-`build_features` snapshot fold creation, per-fold checkpointing (`fold_preds/fold{k}_{oof,test}.parquet` + `fold{k}_info.json`), consistent `eval_folds` scoring, and automated slide artifacts (`summary.md` + `plots/`).

**Tech Stack:** Python ≥ 3.10, `numpy`, `pandas`, `pyarrow` (parquet), `scikit-learn`, `scipy`, `matplotlib` (Agg backend), `pytest`. Optional runtime seeding for `torch`.

**Spec:** `docs/superpowers/specs/2026-10-31-core-lite-design.md`

## Global Constraints

- Zero network access in `utils/core/`; all timestamps use `datetime.now(ZoneInfo("Asia/Jakarta"))`.
- Every custom exception inherits from `TemplateError(ValueError)` and formats messages as `"[Masalah] ...\n[Perbaikan] ..."`.
- `canon_id` is vectorized per dtype (`bool` → `"1"`/`"0"` checked before integer, `int*`/`uint*` → `.astype(str)` with no `2**53` cap, integer-valued floats `< 2**53` → integer string, other floats → `"%.6g"`, `datetime64` → ISO string, NaN → `"<NA>"`).
- `canon_hash` is used only on narrow column sets (`ids_target_hash`, `folds_hash`, `test_ids_hash`); `raw_train_hash` uses `fast_df_hash(df)` (`pd.util.hash_pandas_object`).
- `eval_folds` is determined solely by `cv_strategy` (`[1..n_folds-1]` for `timeseries`, `[0..n_folds-1]` otherwise); `cv_raw`, `cv_post`, `cv_honest`, and `cv` (`= cv_honest`) are always evaluated on `eval_folds` (`cv_post = cv_honest = cv_raw` when `postprocess` returns `{}`).
- `status` (`"ok"` | `"partial"`) reflects only whether all active folds completed; `test_pred_source` (`"fold_avg"` | `"refit"` | `"fold_avg_fallback"`) is tracked separately so skipping `refit_full` due to time budget (`sisa_waktu < max(duration_sec) * 1.25`) keeps `status="ok"`.
- `scores.json` stores `model`, `timestamp`, `owner`, `minutes`, `data_hash`, `status`, and `test_pred_source`, and `lb.json` stores `lb_score`, so `sync_leaderboard()` reconstructs `leaderboard.csv` identically across machines.

## Review Focus

1. Multiclass non-zero-indexed or string labels (e.g. `["cat", "dog", "bird"]`) must align column order between `self.classes_`, `pred_0..pred_{K-1}`, `score()`, `confusion_matrix.png`, and `make_submission()`.
2. Vectorized `canon_id` on float Series containing `np.nan` and `np.inf` must not fail when casting integer-valued floats to `int64` (mask finite integer values before casting).
3. Resuming a run on another machine with a different `socket.gethostname()` must ignore the `owner` difference during `resume_from` config validation and preserve the original run's `owner`, `timestamp`, and relative `run_dir`.
4. `debug=True` subsampling on imbalanced classification or panel timeseries with variable rows per timestamp must never drop a class below `n_folds` rows or split a timestamp in half.
5. `report.py` plotting with `matplotlib` must force the non-interactive `"Agg"` backend and catch any plotting error as a `UserWarning` so a headless machine never fails a run at the reporting step.

import random
import numpy as np
import pandas as pd
import pytest
from utils.core.errors import TemplateError, ConfigError, FoldMismatchError
from utils.core.io import canon_id, canon_hash, fast_df_hash, save_json, load_json, save_parquet, load_parquet

def test_template_error_format():
    err = FoldMismatchError("Set ID berbeda (3 ID hilang)", "Set cfg.folds_path=None untuk membuat fold baru")
    assert isinstance(err, TemplateError) and isinstance(err, ValueError)
    assert "[Masalah]" in str(err) and "[Perbaikan]" in str(err)

def test_canon_id_and_canon_hash_vectorized_equivalences():
    df_int = pd.DataFrame({"id": [7, 8], "y": [1, 0], "na": [1, np.nan]})
    df_flt = pd.DataFrame({"id": [7.0, 8.0], "y": [1.0, 0.0], "na": [1.0, None]})
    df_bool = pd.DataFrame({"id": ["7", "8"], "y": [True, False], "na": [True, np.nan]})
    h = canon_hash(df_int, ["id", "y", "na"], sort_by="id")
    assert h == canon_hash(df_flt, ["id", "y", "na"], sort_by="id")
    assert h == canon_hash(df_bool, ["id", "y", "na"], sort_by="id")

def test_canon_id_large_int64_and_row_order_invariance():
    big1 = np.int64(900719925474099300)
    big2 = np.int64(900719925474099301)
    s = canon_id(pd.Series([big1, big2]))
    assert s.iloc[0] != s.iloc[1]
    assert s.iloc[0] == str(int(big1))

    # Float series with np.inf and np.nan must not fail integer casting
    s_edge = canon_id(pd.Series([1.0, np.inf, np.nan, 2.5]))
    assert list(s_edge) == ["1", "inf", "<NA>", "2.5"]

    df1 = pd.DataFrame({"id": [1, 2, 3], "y": np.array([0.1, 0.2, 0.3], dtype=np.float64)})
    df2 = pd.DataFrame({"id": ["3", "1", "2"], "y": np.array([0.3, 0.1, 0.2], dtype=np.float32)})
    assert canon_hash(df1, ["id", "y"], sort_by="id") == canon_hash(df2, ["id", "y"], sort_by="id")

def test_fast_df_hash_and_io_roundtrip(tmp_path):
    df = pd.DataFrame({"id": range(100), "a": np.linspace(0, 1, 100)})
    assert fast_df_hash(df) == fast_df_hash(df.copy())
    df_mod = df.copy(); df_mod.loc[0, "a"] = 999.0
    assert fast_df_hash(df) != fast_df_hash(df_mod)

    # Unhashable column (e.g. list) falls back to "n/a" instead of raising TypeError
    df_list = pd.DataFrame({"id": [1, 2], "tags": [[1, 2], [3]]})
    assert fast_df_hash(df_list) == "n/a"

    save_json({"n": np.int64(5), "arr": np.array([1.0, 2.0])}, tmp_path / "x.json")
    assert load_json(tmp_path / "x.json") == {"n": 5, "arr": [1.0, 2.0]}

    save_parquet(df, tmp_path / "x.parquet")
    pd.testing.assert_frame_equal(load_parquet(tmp_path / "x.parquet"), df)

def test_seed_everything():
    seed_everything(42)
    a = (random.random(), np.random.rand(3).tolist())
    seed_everything(42)
    b = (random.random(), np.random.rand(3).tolist())
    assert a == b

import numpy as np
import pytest
from utils.core.metrics import get_metric, register_metric, score, is_better

def test_binary_multiclass_and_regression_scoring():
    y_true = np.array([0, 0, 1, 1])
    y_prob = np.array([0.1, 0.6, 0.7, 0.9])
    assert score(y_true, y_prob, "auc", task="binary") == pytest.approx(1.0)
    assert score(y_true, y_prob, "f1", task="binary", threshold=0.5) == pytest.approx(0.8)
    assert score(y_true, y_prob, "f1", task="binary", threshold=0.65) == pytest.approx(1.0)

    classes = ["cat", "dog", "bird"]
    ym_true = np.array(["cat", "dog", "bird", "dog"])
    ym_prob = np.array([[0.8, 0.1, 0.1], [0.1, 0.7, 0.2], [0.1, 0.2, 0.7], [0.2, 0.6, 0.2]])
    assert score(ym_true, ym_prob, "f1_macro", task="multiclass", classes=classes) == pytest.approx(1.0)
    assert score(ym_true, ym_prob, "logloss", task="multiclass", classes=classes) < 0.4

    # QWK on regression rounds and clips to global clip_range; QWK on string classes emits warning
    y_ord = np.array([0, 1, 2, 3])
    y_reg_pred = np.array([-0.4, 1.1, 1.9, 4.2])
    assert score(y_ord, y_reg_pred, "qwk", task="regression", clip_range=(0, 3)) == pytest.approx(1.0)
    with pytest.warns(UserWarning, match="ordinal"):
        score(ym_true, ym_prob, "qwk", task="multiclass", classes=classes)

    assert is_better(0.4, 0.6, "rmse") is True
    assert is_better(0.9, 0.8, "f1") is True

import numpy as np
import pandas as pd
import pytest
from utils.core.config import BaseConfig
from utils.core.cv import get_folds, make_folds_file, split_fold, debug_subsample
from utils.core.errors import DataError, FoldMismatchError

def _make_panel_df():
    rows = []
    idx = 0
    for t in pd.date_range("2026-01-01", periods=12, freq="D"):
        for prov in ["A", "B", "C"]:
            rows.append({"id": f"r{idx}", "dt": t, "prov": prov, "y": float(idx % 2)})
            idx += 1
    return pd.DataFrame(rows)

def test_panel_timeseries_and_split_fold_ids():
    df = _make_panel_df()
    cfg = BaseConfig(task="regression", target="y", metric="rmse", cv_strategy="timeseries",
                     time_col="dt", n_folds=3, ts_gap=1)
    cfg.resolve(); cfg.validate()
    folds_df, _ = get_folds(df, cfg)
    merged = df.merge(folds_df, on="id")
    assert (merged.groupby("dt")["fold"].nunique() == 1).all()

    tr_ids, va_ids = split_fold(df, folds_df, 1, cfg)
    assert tr_ids.isdisjoint(va_ids)
    tr_max_dt = df[df["id"].isin(tr_ids)]["dt"].max()
    va_min_dt = df[df["id"].isin(va_ids)]["dt"].min()
    all_dates = pd.Series(df["dt"].unique()).sort_values().tolist()
    assert all_dates.index(va_min_dt) - all_dates.index(tr_max_dt) > cfg.ts_gap

def test_make_folds_file_and_reuse_across_shuffled_rows(tmp_path):
    df = pd.DataFrame({"id": range(40), "y": [0, 1] * 20, "f": range(40)})
    cfg = BaseConfig(task="binary", target="y", metric="auc", n_folds=4, seed=1, fold_seed=42)
    folds_csv = make_folds_file(df, cfg, out_dir=tmp_path / "folds")
    assert folds_csv.exists() and (tmp_path / "folds" / "folds_meta.json").exists()

    df_shuf = df.sample(frac=1.0, random_state=9).reset_index(drop=True)
    # Pass unresolved BaseConfig (cv_strategy=None) directly to get_folds
    cfg2 = BaseConfig(task="binary", target="y", metric="auc", n_folds=4, seed=999,
                      fold_seed=123, folds_path=str(folds_csv))
    f_loaded, meta = get_folds(df_shuf, cfg2)
    assert meta["source_run"] == "standalone"
    assert meta["cv_strategy"] == "stratified"

    df_bad = df.iloc[1:].copy()
    with pytest.raises(FoldMismatchError, match=r"\[Perbaikan\]"):
        get_folds(df_bad, cfg2)

def test_debug_subsample_preserves_cv_validity():
    # Rare class binary
    df_rare = pd.DataFrame({"id": range(500), "y": [1, 1, 1] + [0] * 497})
    cfg_bin = BaseConfig(task="binary", target="y", metric="auc", debug=True)
    cfg_bin.resolve()
    sub_bin = debug_subsample(df_rare, cfg_bin, max_rows=50)
    assert (sub_bin["y"] == 1).sum() >= cfg_bin.n_folds
    get_folds(sub_bin, cfg_bin)  # must not raise DataError

    df_grp = pd.DataFrame({"id": range(100), "g": np.repeat(range(20), 5), "y": range(100)})

            model, va_p, te_p = super().fit_predict_fold(model, tr_df, va_df, te_df, fold)

def test_blend_rejects_partial_by_default_and_marks_partial_when_allowed(tmp_path):
    tr, te = make_bin_df(45)
    runs_dir = tmp_path / "runs"
    folds_csv = make_folds_file(tr, BaseConfig(task="binary", target="y", metric="auc", n_folds=3),
                                out_dir=tmp_path / "folds")

    r_ok = SklearnBinaryPipe(BaseConfig(
        run_name="ok_run", task="binary", target="y", metric="auc",
        n_folds=3, folds_path=str(folds_csv), runs_dir=str(runs_dir),
    )).run(tr, te)

    clock = FakeClock()

    class SlowPipe(SklearnBinaryPipe):
        def __init__(self, cfg):
            super().__init__(cfg)
            self._clock = clock
        def fit_predict_fold(self, model, tr_df, va_df, te_df, fold):
            clock.advance(60.0)
            return super().fit_predict_fold(model, tr_df, va_df, te_df, fold)

    r_part = SlowPipe(BaseConfig(
        run_name="part_run", task="binary", target="y", metric="auc",
        n_folds=3, max_minutes=0.5, folds_path=str(folds_csv), runs_dir=str(runs_dir),
    )).run(tr, te)
    assert r_part.scores["status"] == "partial"

    # Rejected by default
    with pytest.raises(ConfigError, match=r"allow_partial.*\[Perbaikan\]"):
        load_runs([r_ok.run_dir, r_part.run_dir])

    # Allowed when allow_partial=True, marking resulting ensemble as partial with intersection n_rows_eval
    ens_part = load_runs([r_ok.run_dir, r_part.run_dir], allow_partial=True)
    b_part = blend(ens_part, method="mean", runs_dir=runs_dir, run_name="ens_part")
    assert b_part.scores["status"] == "partial"
    assert (b_part.run_dir / "PARTIAL").exists()
    assert b_part.scores["n_rows_eval"] == r_part.scores["n_rows_eval"]
