# Core Foundation (`utils/core`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the reusable `utils/core` package providing config resolution, canonical data/fold hashing, leak-free CV splitting (including panel time series), metric registry, run artifact tracking with honest OOF scoring, `BasePipeline` hooks, and OOF blending/stacking.

**Architecture:** Focused modules under `utils/core/` (`io`, `seed`, `metrics`, `config`, `cv`, `run`, `pipeline`, `ensemble`) where each module has a single responsibility and no circular imports. `BasePipeline.run()` orchestrates config resolution, snapshot fold generation before feature engineering, per-fold hooks, and raw/postprocessed/honest scoring recorded by `RunManager`.

**Tech Stack:** Python ≥ 3.10, `numpy`, `pandas`, `pyarrow` (parquet), `scikit-learn`, `scipy`, `pytest`. Optional runtime detection for `torch`, `timm`, `transformers`, `lightgbm`, `xgboost`, `catboost`.

**Spec:** `docs/superpowers/specs/2026-10-30-core-design.md`

## Global Constraints

- `seed` is for model/training (`seed_everything`); `fold_seed` is exclusively for `make_folds`.
- Canonical IDs (`str`, integer-valued floats normalized to `"7"`, floats `"%.6g"`, ISO timestamps) are used for all joins and hashes — never DataFrame index or row order.
- `get_folds` and `ids_target_hash` are computed on the pre-`build_features` snapshot `[id_col, target, group_col?, time_col?]`.
- `build_features` must not add, remove, or alter `id_col` values in train or test (`ValueError` if violated); row order may change.
- `fit_transform_fold` may drop rows from `tr`, but must not alter the ID set of `va` or `te` (`ValueError` if violated).
- OOF and `test_pred` always store raw model outputs (`pred` for binary/regression, `pred_0..pred_{K-1}` for multiclass); `Metric.input_type` only affects `score()` and `make_submission()`.
- Honest evaluation uses `fold != k` for non-timeseries (all active folds) and `fold < k` for timeseries (`eval_folds = [1..n_folds-1]`), calling `postprocess(oof_subset, None)`.

## Review Focus

1. Multiclass string or non-zero-indexed labels (e.g., `["cat", "dog", "bird"]` or `[1, 2, 5]`) must map consistently between `scores.json["classes"]`, `pred_0..pred_{K-1}`, and `score()` argmax label decoding.
2. `geo_mean` blending on probabilities containing `0.0` or `1.0` must clip to `[1e-15, 1 - 1e-15]` before log/exp so a single confident zero does not NaN or zero-out the ensemble.
3. Time series `split_fold` when `ts_gap` or early fold leaves zero training rows (`len(train_idx) == 0`) must raise a clear `ValueError` instead of crashing inside a model fit.
4. `postprocess` returning `None` instead of `{}` must be normalized to `{}` without crashing honest scoring.
5. `debug=True` mode must subsample deterministically with `cfg.fold_seed` and force `n_folds=2` during `resolve()` so `folds_meta.json` and `config.json` stay consistent.

```python
import numpy as np
import pandas as pd
import pytest
from utils.core.config import BaseConfig, FoldMismatchError, FoldDataChangedWarning
from utils.core.cv import get_folds, save_folds, split_fold
from utils.core.io import canonical_hash

def _make_panel_df():
    rows = []
    idx = 0
    for t in pd.date_range("2026-01-01", periods=12, freq="D"):
        for prov in ["A", "B", "C"]:
            rows.append({"id": f"r{idx}", "dt": t, "prov": prov, "y": float(idx % 2), "f1": float(idx)})
            idx += 1
    return pd.DataFrame(rows)

def test_panel_timeseries_splits_by_unique_time_and_respects_gap():
    df = _make_panel_df()  # 12 unique dates, 3 rows per date
    cfg = BaseConfig(task="regression", target="y", metric="rmse", cv_strategy="timeseries",
                     time_col="dt", n_folds=3, ts_gap=1, ts_max_train_size=4)
    cfg.resolve(); cfg.validate()
    folds_df, meta = get_folds(df, cfg)
    # Every timestamp must map to a single fold (never split across folds)
    merged = df.merge(folds_df, on="id")
    assert (merged.groupby("dt")["fold"].nunique() == 1).all()
    assert set(folds_df["fold"].unique()) == {-1, 0, 1, 2}

    tr_idx, va_idx = split_fold(df, folds_df, fold=1, cfg=cfg)
    tr_dates = sorted(df.iloc[tr_idx]["dt"].unique())
    va_dates = sorted(df.iloc[va_idx]["dt"].unique())
    all_dates = sorted(df["dt"].unique())
    va_min_rank = all_dates.index(va_dates[0])
    tr_max_rank = all_dates.index(tr_dates[-1])
    assert va_min_rank - tr_max_rank > cfg.ts_gap
    assert len(tr_dates) <= cfg.ts_max_train_size

def test_timeseries_empty_train_raises():
    df = _make_panel_df()
    cfg = BaseConfig(task="regression", target="y", metric="rmse", cv_strategy="timeseries",
                     time_col="dt", n_folds=3, ts_gap=10)
    cfg.resolve(); cfg.validate()
    folds_df, _ = get_folds(df, cfg)
    with pytest.raises(ValueError, match="empty train"):
        split_fold(df, folds_df, fold=0, cfg=cfg)

def test_fold_seed_decoupled_from_model_seed():
    df = pd.DataFrame({"id": range(40), "y": [0, 1] * 20})
    c1 = BaseConfig(task="binary", target="y", metric="auc", seed=1, fold_seed=42, n_folds=4)
    c2 = BaseConfig(task="binary", target="y", metric="auc", seed=999, fold_seed=42, n_folds=4)
    c1.resolve(); c2.resolve()
    f1, m1 = get_folds(df, c1)
    f2, m2 = get_folds(df, c2)

def test_reuse_folds_shuffled_rows_and_feature_change_warns(tmp_path):
    df = pd.DataFrame({"id": range(30), "y": [0, 1] * 15, "f": range(30)})
    cfg = BaseConfig(task="binary", target="y", metric="auc", n_folds=3)
    cfg.resolve()
    raw_h1 = canonical_hash(df, list(df.columns), sort_by="id")
    folds_df, meta = get_folds(df, cfg, source_run="runs/run_01", raw_train_hash=raw_h1)
    folds_csv = save_folds(folds_df, meta, tmp_path)

    # Shuffle rows + modify feature column
    df2 = df.sample(frac=1.0, random_state=7).reset_index(drop=True)
    df2["f"] = df2["f"] * 10
    raw_h2 = canonical_hash(df2, list(df2.columns), sort_by="id")
    cfg2 = BaseConfig(task="binary", target="y", metric="auc", n_folds=3, folds_path=str(folds_csv))
    cfg2.resolve()
    with pytest.warns(FoldDataChangedWarning, match="runs/run_01"):
        loaded, meta2 = get_folds(df2, cfg2, raw_train_hash=raw_h2)
    assert meta2["folds_hash"] == meta["folds_hash"]

    # split_fold aligns by ID, not row position
    tr1, va1 = split_fold(df, folds_df, 0, cfg)
    tr2, va2 = split_fold(df2, loaded, 0, cfg2)
    assert set(df.iloc[va1]["id"]) == set(df2.iloc[va2]["id"])

def test_reuse_folds_raises_on_label_group_or_id_mismatch(tmp_path):
    df = pd.DataFrame({"id": range(20), "y": [0, 1] * 10, "grp": [i // 2 for i in range(20)]})
    cfg = BaseConfig(task="binary", target="y", metric="auc", group_col="grp", n_folds=5)
    cfg.resolve()
    folds_df, meta = get_folds(df, cfg)
    folds_csv = save_folds(folds_df, meta, tmp_path)

    cfg_reuse = BaseConfig(task="binary", target="y", metric="auc", group_col="grp", n_folds=5, folds_path=str(folds_csv))
    cfg_reuse.resolve()

    df_bad_grp = df.copy()
    df_bad_grp.loc[0, "grp"] = 99
    with pytest.raises(FoldMismatchError):
        get_folds(df_bad_grp, cfg_reuse)
```
